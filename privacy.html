Lightweight YouTube viewing for Android TV.

TubeLite TV is an independent Android TV client focused on remote-friendly navigation, efficient YouTube Data API usage, live discovery, account features, Kids Mode, and compatibility with both modern and selected legacy Android TV devices.

Product scope

What TubeLite TV does

The application retrieves YouTube metadata through the official YouTube Data API and plays YouTube content through YouTube's embedded player. It does not host or redistribute YouTube video files.

TV search & discovery

Search, category browsing, channels, playlists, Shorts-oriented discovery, and cached metadata designed to reduce unnecessary API calls.

Live broadcasts

Discovers currently active YouTube broadcasts using official API metadata and filters for playable/embeddable results.

Google account access

Optional Google device OAuth enables account-specific YouTube features such as subscriptions and playlists without asking for the user's Google password.

Remote-first interface

Large TV controls, D-pad navigation, playback overlays, history, autoplay preferences, and an interface intended for 10-foot viewing.

Kids Mode

A parent-PIN mode that narrows discovery and separates local viewing history while keeping account and escape actions constrained.

Quota-conscious design

Results are cached and non-search category feeds use lower-cost API endpoints where appropriate to reduce YouTube API quota consumption.

How a reviewer can access the app

TubeLite TV is currently being tested as an APK before public distribution. A reviewer APK and test instructions can be supplied to Google/YouTube as part of the compliance review process.

Public browsing does not require sign-in. Account-dependent functionality requires an authorized Google account through Google's device authorization flow.

Before submitting the quota form: replace the support/contact placeholders in the Privacy page and, if Google requests direct binary access, add your private reviewer APK or repository release link here.
Compliance posture

Data and user control

No Google password collection

Authentication is handled by Google's OAuth device authorization flow on a separate browser-capable device.

Local app data

Settings, cached metadata, playback history, and resume state may be stored locally. Users can clear local history or uninstall the app.

User-authorized actions

Account-changing actions such as subscribing or unsubscribing are performed only after user authorization and an explicit user action.
