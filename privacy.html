Overview

TubeLite TV is operated by MECIC. The app uses YouTube API Services to retrieve YouTube metadata and the official YouTube embedded player for playback. Users are also subject to Google's and YouTube's applicable terms and privacy policies.

Data processed locally

TubeLite TV may store local watch history and playback resume position, cached YouTube metadata and thumbnails, region and app settings, and—when a user chooses Google sign-in—OAuth tokens and a display label for the authorized YouTube channel/account.

Google / YouTube account access

TubeLite TV does not ask for or collect a user's Google password. Account authorization is performed using Google's limited-input-device OAuth flow. Authorized access is used only for the app features the user chooses, including reading account-related YouTube data and explicit subscription actions.

Token storage

On supported Android versions, TubeLite TV attempts to protect account tokens using Android platform security mechanisms. On some legacy TV firmware, implementation limitations may require app-private local storage. Users may sign out or revoke authorization.

Voice search

When voice search is used, TubeLite TV invokes the speech-recognition service available on the device and uses the returned text as a search query. TubeLite TV does not intentionally retain an audio recording.

Analytics

The current reference build does not transmit analytics by default. If production telemetry is introduced, this notice will be updated to describe the collected fields, purpose, retention, and processors.

Deletion and retention

Users can clear TubeLite-local watch history, sign out, revoke Google authorization, or uninstall the app. Cached API responses are periodically refreshed or expired; local watch history remains until cleared or the app is uninstalled; an OAuth refresh token remains until sign-out, revocation, invalidation, or app-data removal.
